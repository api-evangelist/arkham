Arkham Intelligence operates a production-grade blockchain intelligence platform and REST API that provides entity attribution, address labels, wallet and entity intelligence, transfer and swap tracking, token and market data, portfolio and PnL history, DeFi loan positions, HyperCore and Polymarket analytics, and risk scoring across 20+ chains. The Arkham Intel API (v1.1.0) exposes 135 operations over 128 REST paths plus a WebSocket streaming surface for real-time transfers, authenticated with an API-Key header and billed by a usage-based credit model. Arkham also ships an agent-native x402 pay-per-request surface that lets AI agents buy individual API responses in USDC on Base with no account or key. Arkham was surfaced as a portfolio company of Anthemis and is a crypto / on-chain analytics provider.

**Areas:** Company · Cryptocurrency · Blockchain · Blockchain Intelligence · On-Chain Analytics · Entity Attribution · Wallet Intelligence · Market Data · DeFi · Risk Scoring

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).
