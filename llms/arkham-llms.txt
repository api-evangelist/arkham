# Arkham Intel API v1.1.0

> Production-grade blockchain intelligence API. Entity attribution, address labels, transfer tracking, and on-chain analytics across 20+ chains.

- Base URL: `https://api.arkm.com`
- API Docs: https://arkm.com/api/docs
- OpenAPI Spec: https://arkm.com/openapi.json
- Full docs (single file): https://arkm.com/llms-full.txt
- Schemas: https://arkm.com/llms/schemas/
- Endpoint doc pattern: https://arkm.com/llms/<method>-<path>.md (e.g. `POST /intelligence/address/batch/all` → https://arkm.com/llms/post-intelligence-address-batch-all.md)
